# A 股妖股年度名单序列（2016–2026）

统一口径的全市场妖股扫描，每年一个模块，构成 2016–2026 完整年度序列。

## 统一筛选口径

- **触发条件（满足其一即入选）**：①任意连续 5 个交易日涨幅 ≥50%（按板块标准化）；②连续涨停 ≥6 天
- **标准化**：标准化涨幅 = 原始涨幅 ×（10% ÷ 该板块当日涨跌幅限制）。主板 ×1；创业板 2020-08-24 前 ×1、之后 ×0.5；科创板 ×0.5；北交所 ×1/3
- **涨停阈值**：主板 9.8%；创业板 2020-08-24 前 9.8%、之后 19.8%；科创板 19.8%；北交所 29.8%
- **剔除**：事件期间已 ST/*ST；上市不足 20 个交易日的次新股/一字板
- **事件聚合**：同一股票相邻命中日按交易日间隔 >5 切分为独立事件

## 数据来源说明

- **2016–2024**：原始九年扫描（2024 年末交付）。沪深用新浪财经后复权日 K，北交所用不复权日 K；含期间已退市股票（5847 只代码）；上涨原因 A 档（642 个连板及著名事件逐只梳理）/ B 档（1307 个纯涨幅事件按当月主线标注）
- **2025**：原始文件缺失，2026-11-07 用同一管线复算重建（baostock + 雪球 + 新浪北交所）；「上涨原因/归类」列随后逐股调研补齐
- **2026**：同管线全量扫描（baostock + 雪球 + 新浪北交所）；原因 A 档逐只调研 + B 档按月主线

各年 Excel 均为三表结构：事件汇总 / 逐日明细 / 口径说明。
