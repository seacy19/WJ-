# WJ情绪龙头策略·独立完整版

> 版本：独立执行版 v1.0  
> 适用市场：A股  
> 交易周期：1～7个交易日  
> 策略定位：在真实短线主线爆发时，寻找资金最认可、辨识度最高的情绪龙头，并且只在合理的分歧转强节点参与。  
> 边界：本策略不负责选择中线基本面龙头，也不负责选择低位补涨股；两者应使用各自独立规则。

---

## 一、策略核心

情绪龙头交易不是“看到涨停就追”，而是依次回答五个问题：

1. 当前市场是否允许做高波动短线交易？
2. 上涨的是一个真实题材，还是几只股票偶然异动？
3. 催化最终会影响谁的收入、利润或订单，盘面炒作与利润落点是否一致？
4. 谁才是题材内真正的资金核心，而不是跟风票或概念沾边票？
5. 次日是否出现可执行的分歧转强，而不是已经一致加速、没有安全边际？

完整链路为：

```text
市场授权
→ 真实题材识别
→ 催化与利润落点验证
→ 拉全题材候选
→ 五项资格筛选
→ 龙头横向排序
→ 曲线与过热度分级
→ 次日竞价和盘中触发
→ 仓位、止损、止盈和时间退出
```

任何一只股票进入候选池，都不等于已经出现买点。筛选解决“看谁”，盘口触发解决“何时做”。

---

## 二、适用场景与禁用场景

### 2.1 适用场景

同时具备以下特征时，才启用本策略：

- 市场出现明确的政策、事件、资金或板块共振催化；
- 同一真实题材内有多只股票同步走强，而不是孤立上涨；
- 至少出现一只能够带动板块的高辨识度核心股；
- 交易预期主要来自短线情绪、资金强化和题材扩散；
- 计划持仓周期为1～7个交易日，接受快速证伪和快速退出。

### 2.2 不适用场景

以下情况不使用本策略：

- 公司依靠业绩兑现和产业趋势持续创新高，应归入基本面龙头策略；
- 股票尚在低位、主要交易龙头断板后的资金外溢，应归入补涨策略；
- 只有单只股票因公告涨停，同题材没有联动；
- 市场无法形成清晰题材边界，催化来源也无法确认；
- 流动性不足，无法按计划止损；
- 交易者希望中长期持有，却使用短线情绪理由作为买入依据。

## 三、第零步：市场环境授权

市场环境不决定候选池是否需要筛选，但决定能否执行、使用多大仓位以及是否允许追强。

### 3.1 指数状态

使用指数15分钟、60分钟和日线EXPMA(12,50)判断风险偏好：

| 市场状态 | 判断 | 执行权限 |
|---|---|---|
| 强势 | 15分钟金叉，60分钟不压制，日线环境稳定 | 可正常执行，仍须等待个股触发 |
| 修复 | 15分钟金叉，但60分钟仍为死叉或存在明显压力 | 只做最强题材核心，降低仓位，禁止追一致加速 |
| 震荡 | 15分钟反复交叉，主线轮动快 | 缩短持仓，只接受题材与个股双确认 |
| 弱势 | 15分钟死叉且指数持续走低，亏钱效应扩散 | 候选照常筛选，实盘原则上等待；若交易，只能极小仓参与最强逆势核心 |

EXPMA只是市场状态和节奏工具，不是个股选股器，也不构成单独买入理由。

### 3.2 短线情绪状态

同步检查：

- 涨停家数、跌停家数和炸板率；
- 高位股是否批量断板或出现跌停；
- 前一日强势题材是否有正反馈；
- 全市场上涨家数与下跌家数；
- 成交额是否支持题材扩散；
- 核心股是否出现严重负反馈。

市场极弱时，逆势题材可以被列入观察，但不能自动被理解为新周期主线。逆势上涨可能来自产业催化，也可能只是避险交易，必须等次日延续验证。

### 3.3 环境与仓位的关系

| 环境评级 | 单只初始仓位上限 | 总体原则 |
|---|---:|---|
| 强势 | 15%～20% | 可分两笔确认，仍不追无承接的一致高开 |
| 修复 | 8%～12% | 只做最强核心，确认后介入 |
| 震荡 | 5%～10% | 快进快出，不做后排 |
| 弱势 | 0%～5% | 以观察为主；没有强确认就不交易 |

仓位为风险上限，不是必须用满的目标。

## 四、真实题材识别

### 4.1 四类驱动

题材至少存在一类明确驱动：

| 驱动 | 核查内容 |
|---|---|
| 政策驱动 | 正式文件、监管规则、产业规划、财政或信贷支持是否改变需求或供给 |
| 事件驱动 | 产品发布、技术突破、订单、价格变化、外部限制或突发事件是否形成新增预期 |
| 资金驱动 | 板块是否连续放量，核心股是否获得持续增量资金，而非一日脉冲 |
| 共振驱动 | 同一真实题材是否出现批量涨停和同步异动；涨停不少于8只为强共振条件 |

两个以上驱动同时成立，题材等级高于单一驱动；但驱动数量不能代替题材边界核验。

### 4.2 真实题材的三个支点

只有同时满足以下三点，才视为同一真实题材：

1. **驱动同源**：上涨来自同一个政策、产业变化、产品涨价、技术突破或事件。
2. **产业链可串联**：公司处于同一受益环节，或能够沿上游—中游—下游说明受益关系。
3. **盘面同步**：核心股上涨时，其他成员出现同步拉升、放量或封板；长期不跟随者剔除。

软件中的行业或概念标签只能用来拉初始名单，不能直接定义真实题材。题材过宽时要做减法，漏标时要根据业务实质做加法。

### 4.3 题材边界必须写清楚

每次报告都必须明确：

```text
准确题材名称：
直接催化：
核心受益环节：
真实题材成员：
被排除的宽泛概念成员：
证据等级：强 / 中 / 弱
```

不能用一个宽泛名词，把利润来源完全不同的公司混为同一主线。

## 五、催化与利润落点

利润落点不能只写“受益于政策”或“行业景气提升”，必须把因果链拆开。

### 5.1 标准分析链条

```text
催化发生了什么
→ 改变了哪一类需求、供给、价格或资本开支
→ 哪个产业环节获得订单、销量、价格或利用率提升
→ 收入如何变化
→ 成本和费用是否会抵消收入增长
→ 利润弹性最终落在哪些公司
→ 当前股价已经计价到什么程度
```

### 5.2 必须回答的八个问题

1. 需求是新增需求，还是原有需求提前释放？
2. 受益来自销量、售价、市场份额、产能利用率还是政策补偿？
3. 受益是一次性的，还是可以持续多个季度？
4. 哪个环节拥有定价权、技术壁垒、产能或牌照？
5. 公司是否真的拥有相关业务，相关收入占比和利润占比多大？
6. 原材料、折旧、财务费用、竞争降价是否会吞噬利润？
7. 盘面最强者是否也是利润最直接的受益者？如果不是，它的上涨主要是情绪溢价还是预期差？
8. 市场此前是否已充分交易这一逻辑，剩余预期差是什么？

### 5.3 利润落点评级

| 等级 | 定义 | 对策略的影响 |
|---|---|---|
| A 直接兑现 | 订单、售价、销量或份额能够直接改善，并有较强盈利传导 | 可提高持续性评分 |
| B 间接受益 | 产业逻辑成立，但利润传导受资源条件、成本、价格机制等约束 | 可以做情绪龙头，但不能包装成高确定性基本面机会 |
| C 概念映射 | 业务占比低、受益链条长或只有名称关联 | 仅凭情绪强度观察，显著降级 |
| D 无法验证 | 找不到业务实质或证据冲突 | 剔除正式候选 |

情绪龙头允许利润落点不是最优，但必须如实说明：它到底是“基本面受益＋情绪强化”，还是“主要依赖资金和辨识度”。

## 六、候选池生成

### 6.1 先拉全，再排序

不得先凭印象指定一只股票。应从以下来源拉全候选：

- 真实题材内当日涨停股；
- 率先启动、率先封板的核心股；
- 连板高度或阶段涨幅领先者；
- 成交额和换手显著放大的容量核心；
- 业务受益最直接但尚未充分表现的成员。

候选池至少记录：证券代码、总市值、成交额、换手率、涨停时间、封板状态、连板数、近5日/10日涨幅、量比、关键均线、真实业务关联和当日催化。

### 6.2 风险筛查

**硬排除：**

- ST或*ST股票。

**显著降级：**

- 近期存在业绩暴雷、重大减持、监管调查等重大利空；
- 日均成交额低于5000万元，流动性不足；
- 盘口反复炸板且没有板块承接；
- 短期涨幅过大、乖离率过高；
- 题材关联只能依赖模糊概念标签。

## 七、情绪龙头资格筛选

### 7.1 五项基础指标

| 指标 | 基础标准 | 性质 |
|---|---|---|
| 总市值 | 50亿～300亿元 | 弹性优选，不是绝对排除；弱市可提高容量核心权重 |
| 换手率 | 5%～15% | 活跃度优选；过低缺少参与，过高可能分歧失控 |
| 量价配合 | 放量突破关键位置或放量封板 | 核心条件 |
| 题材共振 | 真实题材内涨停不少于8只 | 强主线标准；不足时只能按局部题材降级处理 |
| 平台偏好 | 创业板优先，北交所可选，主板不排除 | 加分项，不是硬门槛 |

五项指标必须逐条取数，不得只验证其中几项后凭印象补全。

### 7.2 龙头横向排序

基础资格通过后，再在全部候选中比较：

1. **带动性**：个股拉升后，是否带动题材成员同步上涨；这是最重要的龙头特征。
2. **启动与封板顺序**：率先启动、率先封板者优先，但一字板若缺乏可交易性需单独处理。
3. **封板质量**：封单稳定、炸板少、回封快、板上成交结构健康者优先。
4. **成交与流动性**：成交额能够容纳资金，量能放大但未出现失控式换手。
5. **连板高度或阶段强度**：高度领先会增加辨识度，也会提高兑现风险，必须两面评价。
6. **市场讨论度**：只作为人气辅助，不能替代行情数据和带动性。
7. **利润落点**：受益更直接、预期差更大的公司，次日更容易获得持续资金。

不能只凭“最先涨停”认定唯一龙头。若带动性、成交额、封板质量和题材地位分别由不同股票占据，应明确列为并列核心，并在次日用竞价和盘中表现完成最终选择。

### 7.3 龙头综合评分

建议采用100分制，便于横向比较：

| 维度 | 权重 |
|---|---:|
| 真实题材强度与持续性 | 20 |
| 个股带动性 | 20 |
| 启动、封板与连板辨识度 | 15 |
| 量价结构与成交承载 | 15 |
| 催化及利润落点 | 15 |
| 曲线健康度与短期过热度 | 10 |
| 公告、流动性等风险 | 5 |

评分解释：

- 80分以上：正式核心候选；
- 70～79分：条件候选，只等强盘口确认；
- 60～69分：观察候选，不主动交易；
- 60分以下：剔除。

评分不能掩盖硬伤。题材无法验证、重大利空或流动性明显不足时，即使其他分数高，也不能进入正式候选。

## 八、曲线与过热度处理

曲线不是情绪龙头的一票否决项，但必须影响候选级别、买点要求和仓位。

### 8.1 必查数据

- MA5、MA10、MA20、MA60、MA120、MA250；
- 各均线斜率；
- 股价相对各均线的位置；
- 近5日、10日和20日涨幅；
- 距离阶段高点的回撤；
- 放量突破、缩量加速还是巨量滞涨；
- 是否存在长上影、连续炸板或高位放量分歧。

### 8.2 曲线分级

| 曲线等级 | 典型特征 | 执行方式 |
|---|---|---|
| A 健康上升 | 中长期均线向上，短中长期结构协调，乖离可控 | 正常候选，仍等盘口触发 |
| B 短线转强 | 短期均线转强，中长期结构尚未完全修复 | 条件候选，仓位下调一级 |
| C 超跌急拉 | 长期均线仍向下，短期连续大涨或连板 | 只接受充分分歧后的重新转强，禁止一致追高 |
| D 高位衰竭 | 巨量滞涨、长上影、炸板频繁、明显远离均线 | 原则上回避 |

### 8.3 特别漂亮的曲线如何处理

即使股票不属于当天最强真实主线，只要曲线结构特别健康、量价稳定、相对强度突出，仍可进入“独立曲线观察池”，不因主题不足而直接删除。但必须遵守：

- 不得冒充情绪主线龙头；
- 必须单独写清它的上涨驱动和利润逻辑；
- 若没有题材共振，仓位和评级不能等同于主线核心；
- 只有出现自身放量突破或回踩确认，才转为可交易候选。

这样既避免用主题标签误杀好曲线，也避免把没有板块支持的个股强行包装成情绪龙头。

## 九、反向校验：只做降级，不机械否决

反向校验的目的不是用一个指标否定题材，而是防止确认偏差。检查：

- 题材指数或代表性股票是否同步走强；
- 上涨是否只集中在一两只高位股；
- 利润最直接的核心受益公司是否普遍获得资金认可；
- 直接受益者弱、概念映射者反而更强时，是否说明交易主要依靠情绪而非产业兑现；
- 题材成交额是否扩张，还是涨停数量很多但实际承载不足；
- 次日是否出现大面积负反馈。

处理规则：

- 校验支持：维持评级；
- 出现一项明显矛盾：标记原因，评级或仓位下调一级；
- 多项矛盾且无法解释：降为局部情绪题材，只保留最强核心观察；
- 证据直接推翻催化或业务关系：剔除。

行业ETF涨跌只能作为辅助，因为ETF权重结构可能与当日短线题材边界不同，不能单独决定题材真假。

## 十、次日执行条件

### 10.1 盘前计划

对每只正式候选预先写清：

```text
前收盘价：
合理竞价区间：
一致过热线：
首个承接观察位：
分歧低点确认方式：
买入触发：
取消条件：
初始仓位：
硬止损价：
第一止盈区：
```

价格必须根据个股前收盘、波动率、支撑位和涨停制度计算，不能把某个固定绝对价格套到所有股票。

### 10.2 竞价分级

以下区间为普通10%涨跌幅股票的通用参考，20%涨跌幅股票应结合波动率适当放宽，但不得机械翻倍：

| 竞价表现 | 默认处理 |
|---|---|
| 低开超过3% | 先观察是否为板块集体退潮；没有快速承接不接 |
| 低开3%以内至平开 | 可观察弱转强，但不能在仍向下时抄底 |
| 平开至高开3% | 最适合等待分歧转强 |
| 高开3%～5% | 只观察，不抢开盘；必须有板块与成交确认 |
| 高开超过5% | 默认放弃追价；除非充分换手后重新形成低风险结构 |
| 一字涨停 | 不排队；观察题材扩散和后续可交易节点 |

竞价区间只是第一层过滤，不能单独触发买入。

### 10.3 板块确认

个股触发前，至少确认：

- 真实题材仍处市场强度前列；
- 前排核心没有集体低开低走；
- 涨停梯队没有在开盘后快速瓦解；
- 题材成交额没有明显萎缩；
- 个股拉升时至少有若干核心成员同步响应。

如果只剩单只股票独立冲高，而题材成员普遍走弱，不能把普通反抽认定为龙头转强。

### 10.4 唯一标准买点：分歧转强

标准触发顺序：

```text
竞价不过热
→ 开盘出现合理换手和分歧
→ 回落不破预设承接位，或跌破后快速收回
→ 题材核心没有瓦解
→ 个股重新放量收回分时均价或开盘关键位
→ 再次向上时小仓介入
```

“先跌后反抽”不等于分歧转强。真正的分歧转强必须同时具备：下跌风险得到控制、主动买盘重新占优、板块仍有联动。

### 10.5 分批原则

- 第一笔：触发分歧转强时使用计划仓位的1/2；
- 第二笔：回踩确认不破，或板块再次增强时再补至计划仓位；
- 第一笔后迅速证伪，不得通过补仓摊低成本；
- 当日已经快速拉升并远离触发位后，不追加追价。

---

## 十一、取消交易条件

出现任意一项，取消当日买入计划：

- 竞价明显超过预设过热线，开盘继续缩量加速；
- 真实题材核心成员集体低开低走；
- 个股跌破承接位后不能快速收回；
- 个股冲高时板块没有任何响应；
- 涨停梯队快速缩减，炸板率显著上升；
- 大盘出现失控式普跌或高位股批量跌停；
- 临时出现重大利空、监管风险或交易异常；
- 预期止损空间超过5%，导致盈亏比不足2:1；
- 盘口触发晚于计划，股价已经大幅远离合理介入位。

计划取消后，当日不因害怕错过而临时降低标准。

---

## 十二、止损、止盈与持仓

### 12.1 止损

| 类型 | 规则 |
|---|---|
| 逻辑止损 | 题材催化被证伪，或真实题材已退潮，优先退出 |
| 盘口止损 | 分歧转强后再次跌破当日承接低点，且板块同步转弱，提前退出 |
| 硬止损 | 实际买入价下方5%，无条件执行 |
| 时间止损 | 持有满3个交易日仍未获得至少2%收益，退出 |
| 最长持仓 | 原则上不超过7个交易日；需要转为中线持有时，必须重新通过基本面龙头策略评估 |

逻辑和盘口已经证伪时，不必等到机械的-5%。

### 12.2 止盈

| 类型 | 规则 |
|---|---|
| 第一目标 | 浮盈达到8%～10%，卖出至少一半 |
| 快速拉升 | 1～2日上涨超过12%，主动减仓，不把短线利润变成长期持仓 |
| 动态止盈 | 浮盈超过8%后，从高点回撤超过3%，退出剩余仓位 |
| 题材退潮 | 龙头尚未触及目标，但题材核心批量转弱，优先保护本金和已有利润 |

每笔交易预期盈亏比至少2:1。若合理止损为5%，预期空间不足10%，不执行。

## 十三、候选分层与输出标准

每日必须同时给出完整候选池和分层结论，不能只报一只股票。

### 13.1 三层候选池

| 层级 | 定义 | 操作 |
|---|---|---|
| 正式核心候选 | 真实题材、龙头地位、量价、风险和曲线综合通过 | 等次日盘口触发 |
| 条件候选 | 主要条件成立，但曲线、利润落点或市场环境存在明显缺口 | 降仓，只接受更强确认 |
| 独立曲线观察 | 非当日最强主线，但曲线和相对强度特别漂亮 | 单列跟踪，不冒充情绪龙头 |

### 13.2 每只股票必须披露

```text
股票名称与代码
候选层级
准确题材及催化
详细利润落点
总市值、成交额、换手率、量比
题材真实涨停数
连板数与近5日/10日涨幅
龙头带动性及横向排序
MA5/10/20/60/120/250及斜率
曲线是否完整通过；未通过哪一项
竞价允许区间
标准买入触发
取消条件
计划仓位
止损、止盈和时间退出
最可能推翻逻辑的证据
```

若数据缺失，必须标明缺失项以及它对判断的影响，不能以估计值代替。

## 十四、每日运行清单

### 收盘后筛选

- [ ] 获取指数和短线情绪数据；
- [ ] 列出当日全部强势题材；
- [ ] 对每个题材核查直接催化；
- [ ] 按驱动同源、产业链可串联、盘面同步划定真实题材；

- [ ] 统计真实题材涨停数；
- [ ] 拉全候选，不先锚定个股；
- [ ] 逐只完成风险、五指标、龙头排序和曲线核查；
- [ ] 分为正式核心、条件候选和独立曲线观察；
- [ ] 为正式候选制定次日价格和触发计划。

### 次日竞价

- [ ] 检查指数环境是否恶化；
- [ ] 检查题材核心竞价是否集体正反馈；
- [ ] 检查候选是否一致过热；
- [ ] 更新承接位和取消条件；
- [ ] 没有触发时保持观察，不预判买入。

### 盘中执行

- [ ] 等待合理分歧；
- [ ] 验证板块联动；
- [ ] 验证个股主动买盘与放量收复；
- [ ] 触发后分批，证伪后立即退出；

- [ ] 入选原因是否真实有效；
- [ ] 龙头是否真正带动题材；
- [ ] 买点是否符合分歧转强，而非情绪冲动；
- [ ] 曲线降级是否落实到仓位；
- [ ] 失败来自题材错误、龙头识别错误、买点错误还是纪律错误；
- [ ] 只根据多次样本修正规则，不因单一案例随意新增硬阈值。

## 十五、决策伪代码

```text
完整拉取当日题材与候选

FOR 每个题材：
    IF 无明确驱动 OR 无法建立产业链联系：
        降级或剔除
    ELSE：
        用盘面同步划定真实题材
        分析需求变化与利润落点
        统计真实题材涨停数

FOR 每只候选：
    IF ST/*ST OR 业务关系无法验证：
        剔除
    ELSE：
        核查五项基础指标
        与全部核心候选横向比较
        核查完整曲线与短期过热度
        核查公告、流动性和题材风险
        计算综合评分并分层

IF 股票不属于最强题材 BUT 曲线特别漂亮：
    放入独立曲线观察池
    不归类为情绪龙头

次日：
    IF 市场失控 OR 题材核心集体转弱 OR 竞价过热：
        取消交易
    ELSE IF 出现“合理分歧 + 板块不弱 + 放量重新转强”：
        分批介入
    ELSE：
        继续观察

持仓后：
    优先执行逻辑止损和盘口止损
    最迟执行-5%硬止损
    3日不兑现执行时间止损
    +8%～+10%分批止盈
    原则上7日内结束交易
```

## 十六、策略的本质限制

情绪策略赚取的是资金在短时间内对同一叙事形成共识后的溢价，并不天然等于公司长期价值上升。因此：

- 龙头辨识度越高，潜在情绪溢价越高，但兑现风险也越大；
- 板块共振能提高胜率，却不能保证次日延续；
- 利润落点越间接，交易越依赖资金接力，持仓时间应越短；
- 曲线越差、短期涨幅越大，越需要充分分歧和更低仓位；
- 没有标准买点时，正确动作不是降低标准，而是放弃交易。

本策略的最终纪律是：

> **先确认真实题材，再确认真正龙头；先等分歧释放风险，再用转强确认资金回流。只做计划内交易，不把观察标的写成无条件买入。**

---

> 风险提示：以上为策略研究与交易规则整理，不构成任何个股推荐或收益承诺。情绪交易波动大、证伪快，必须以可承受损失为仓位上限，并严格执行止损。
