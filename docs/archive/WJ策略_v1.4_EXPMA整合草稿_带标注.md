### [调整] EXPMA模块的位置

建议将EXPMA模块放在：


### [调整] 为什么不放在“风险筛查”之后

风险筛查解决的是：

```text
这个股票有没有硬伤？
是否ST？
是否有重大利空？
流动性是否太差？
```

EXPMA解决的是：

```text
当前市场环境适合出手吗？
现在是主升、反弹、震荡，还是退潮？
短线是该追、该等，还是该减？
```

所以EXPMA不是个股风险项，也不是选股条件本身，而是进入个股策略前的“市场状态层”。如果放在风险筛查之后，容易被误解为“某只股票通过风险筛查后，再用EXPMA过滤个股”，这不符合会议原意。

### [新增] 推荐定位

EXPMA在WJ策略中应定位为：

```text
市场状态层 / 择时层 / 行情阶段识别层
```

不是：

```text
个股选股器
个股买卖硬规则
单一胜率指标
```

## 二、拟插入正文：第零步：市场状态与择时框架（EXPMA）

> 建议插入位置：`策略概述`之后，`第一步：风险筛查`之前。

### [新增] 第零步：市场状态与择时框架（EXPMA）

EXPMA用于判断市场状态、场外情绪转折与行情阶段，不作为单一个股的核心买卖依据。

WJ策略中，EXPMA正式参数采用：

```text
EXPMA(12,50)
```

其中：

```text
EXPMA12 = 短期价格共识
EXPMA50 = 中期价格共识
```

金叉含义：

```text
EXPMA12 > EXPMA50
= 短期价格共识强于中期价格共识
= 市场短周期风险偏好修复
```

死叉含义：

```text
EXPMA12 < EXPMA50
= 短期价格共识弱于中期价格共识
= 市场短周期风险偏好下降
```

### [新增] EXPMA计算公式

EXPMA的计算公式为：

```text
EXPMA_t = α × Close_t + (1 - α) × EXPMA_{t-1}
α = 2 / (N + 1)
```

其中：

```text
Close_t = 当前K线收盘价
N = EXPMA周期参数
α = 当前价格权重
```

在EXPMA(12,50)中：

```text
EXPMA12: α = 2 / (12 + 1) = 2 / 13 ≈ 15.38%
EXPMA50: α = 2 / (50 + 1) = 2 / 51 ≈ 3.92%
```

因此，EXPMA12对近期价格更敏感，EXPMA50更稳定。金叉/死叉的本质不是“线条交叉”本身，而是短期资金定价相对于中期资金定价发生了方向变化。

## 三、多周期使用框架

### [新增] 小趋势服从大趋势

EXPMA使用时必须遵守：

```text
小趋势服从大趋势。
指数决定环境，板块决定方向，个股决定弹性，EXPMA决定时机。
```

不同周期的作用不同：

```text
15分钟K线EXPMA：短线进出场节奏，主要用于观察大盘场外情绪短周期转折
60分钟K线EXPMA：中短线压力与趋势确认，用于判断小级别反弹是否受制于更大级别
日线EXPMA：波段状态与市场大环境
周线、月线EXPMA：行业或大级别趋势阶段
```

### [新增] 15分钟EXPMA的定义

15分钟EXPMA指：

```text
基于15分钟K线收盘价计算出的EXPMA12与EXPMA50。
```

它不是普通分时线，也不是1分钟盘口波动。

A股每个交易日约有16根15分钟K线：

```text
4小时交易时间 × 60分钟 / 15分钟 = 16根
```

因此：

```text
15分钟EXPMA12 ≈ 最近12根15分钟K线的指数移动平均 ≈ 最近3小时交易状态
15分钟EXPMA50 ≈ 最近50根15分钟K线的指数移动平均 ≈ 最近3.1个交易日交易状态
```

## 四、大盘15分钟EXPMA的短线用法

### [新增] 大盘15分钟EXPMA金叉

当大盘15分钟K线EXPMA12上穿EXPMA50时，说明短周期风险偏好开始修复，场外资金可能重新进场。

此时可开始重点关注：

```text
前期强势股的超跌反弹
新热点是否出现
新热点中是否有持续逻辑
主线核心标的是否重新走强
```

该信号主要用于短线进出场节奏，不等同于中长期牛市确认。

### [新增] 大盘15分钟EXPMA死叉

当大盘15分钟K线EXPMA12下穿EXPMA50时，说明短周期风险偏好下降，场外资金趋于谨慎。

此时应注意两类风险：

```text
追涨胜率下降
强势股也容易补跌
```

二者区别如下：

```text
追涨胜率下降 = 不适合新追高，冲高后承接容易不足
强势股容易补跌 = 原本强势或已经持有的高位股，也可能因风险偏好下降而回撤
```

因此，15分钟死叉阶段应减少盲目追高，等待下一次明确转折。

## 五、牛市、熊市、震荡市中的用法

### [新增] 牛市

牛市中，应以日线级别趋势为主，重点盯龙头、做主升段。

```text
牛市核心：盯龙头，做主升段，争取吃到大级别上涨。
```

15分钟EXPMA可用于优化入场与加减仓节奏，但不应因为小级别波动轻易否定日线主升趋势。

### [新增] 熊市

熊市中，15分钟EXPMA金叉主要用于博弈前期强势股的超跌反弹。

```text
熊市核心：等待大盘15分钟金叉后，再观察前期强势股是否有反弹机会。
```

在大盘15分钟未金叉前，不宜盲目博第二波。

### [新增] 震荡市

震荡市中，EXPMA容易反复金叉死叉，指标会钝化。

此时更考验选股能力，应聚焦：

```text
前期强势龙头
有资金记忆的妖股
业绩浪标的
具备持续逻辑的新热点核心
```

震荡市不能机械理解为“金叉就买、死叉就卖”，必须结合个股股性、题材持续性和市场主线强弱。

## 六、行业指数的EXPMA用途

### [新增] 行业指数不用15分钟EXPMA做精细跟踪

会议中认为，EXPMA不适合用来跟踪细分行业指数的短周期波动。细分行业指数在15分钟级别容易受成分股权重、短线资金扰动和局部交易影响，指导意义有限。

### [新增] 行业指数适合用中长期EXPMA判断阶段

行业指数更适合观察日线、周线、月线级别EXPMA，用于判断行业行情推进到什么阶段。

可重点观察：

```text
日线EXPMA金叉：行业进入短期可交易阶段
周线EXPMA金叉：行业中期趋势可能开始形成
月线EXPMA金叉：行业可能逐步脱离长期低谷
```

行业指数中长期EXPMA向上，是行业景气度预期被市场持续确认的重要信号。

这类信号可用于捕捉：

```text
景气度正在提升的行业
长期低位后开始右侧抬头的行业
从谷底逐步脱离的行业
资金开始持续重新定价的行业
```

## 七、个股层面的边界

### [新增] 个股EXPMA不作为核心买卖依据

具体到细分个股，EXPMA很难单独产生稳定指导作用。

原因是个股价格会受到多种因素影响：

```text
公司基本面
题材持续性
龙头地位
股性
筹码结构
公告与事件扰动
短线资金拉抬
流动性
```

因此，个股选择仍以WJ策略原有标准为主：

```text
龙头地位
题材持续性
业绩弹性
主升段位置
股性与辨识度
补涨空间
```

EXPMA只负责辅助判断时机，不负责替代选股。

### [新增] 个股重于指数，但指数决定出手环境

会议中的“个股重于指数”应理解为：

```text
最终收益来自个股弹性，而不是指数本身。
```

但指数仍然重要，因为指数EXPMA用于判断：

```text
当前是否适合出手
追涨胜率是否下降
强势股是否可能补跌
前期强势股是否出现反弹窗口
```

因此二者关系是：

```text
指数决定环境
板块决定方向
个股决定弹性
EXPMA决定时机
```

## 八、贵州燃气案例

### [新增] 案例：2018年2月贵州燃气

2018年2月，大盘整体走弱后，资金回流至前期强势股。贵州燃气作为前期强势龙头，在大盘15分钟级别出现转折信号后，出现超跌反弹机会。

案例意义：

```text
弱市中不是完全没有机会；
弱市机会更多集中在前期强势股、老龙头、资金记忆强的标的；
入场应等待大盘15分钟级别出现明确转折；
大盘反弹不代表所有股票都有机会，高位股也可能补跌；
案例不能泛化为“所有前期强势股都会反弹”。
```

## 九、数据源补充

### [新增] 15分钟K线数据源

15分钟EXPMA需要15分钟K线数据。若数据缺失，不得臆测金叉/死叉状态。

数据源优先级：

```text
1. 通达信本地导出的15分钟K线数据：优先使用
2. TuShare分钟线：可作为受限备用
3. 若无法取得15分钟K线：必须明确提示“15分钟EXPMA状态无法判断”
```

输出中应明确：

```text
15分钟EXPMA是否有数据支持；
使用的数据来源是什么；
若无数据，缺失的是哪一类数据；
不得凭记忆或印象补写金叉/死叉。
```

## 十一、对原文的具体影响

### [调整] 原“第一步：风险筛查”

原“第一步：风险筛查”建议顺延为：

```text
第一步：风险筛查
```

但在整体流程上，它已经不是最先执行的市场判断；最先执行的是：

```text
第零步：市场状态与择时框架（EXPMA）
```

风险筛查仍保留原有功能：排除ST、重大利空、流动性过差等个股风险。

### [调整] 原“通用优选项：均线位置”

原“通用优选项：均线位置”仍作为个股层面的优选项保留，不与EXPMA混用。

区别如下：

```text
EXPMA：主要看大盘/行业/市场状态
5日线、10日线位置：主要看短线个股买点舒适度
```

### [调整] 原“日内买点纪律”

原“日内买点纪律”可在执行时增加一句：

```text
若大盘15分钟EXPMA处于死叉或未明确转强状态，短线追高动作应更谨慎；若大盘15分钟EXPMA金叉后，优先观察前期强势股超跌反弹与新热点核心标的。
```

但这句话不构成个股买入的一票否决。
