# WJ策略

本仓库归档 WJ 策略的策略文档、筛选与审计脚本，以及历史研究和回测结果。

## 主要内容

- [WJ补涨策略 v2：数值化新版规则](WJ补涨策略_v2_数值化规则_2026-11-07.md)：当前补涨分支规则；十年完整回测尚未验证。
- `WJ策略_v1.4_EXPMA整合正式版.md`：其余策略分支及 EXPMA 说明；同名 DOCX 为排版版本。补涨分支与 v2 冲突时以 v2 为准。
- `WJ情绪龙头策略_独立完整版.md`、`WJ策略_整合版_2026-06-30.docx`：策略分支与历史版本。
- 根目录 Python 脚本：筛选、行情探测、复盘审计和文档构建流程。
- `*_output.json`、`*_output.md`、CSV：历史研究快照、筛选结果及审计产物。
- `wj_backtest_results/`：回测汇总、交易明细、信号和净值曲线。
- `mcp_servers/`：行情 MCP 服务源代码。运行凭证应通过本机环境变量提供。

## 运行环境

核心脚本主要使用 Python、pandas、numpy 和 TuShare Pro；行情 MCP 服务还使用 `mcp` 等依赖。需要访问数据服务的脚本应在本机设置相应 API 凭证，不要把真实密钥写入仓库。

## 敏感信息

API 密钥、环境文件、本机缓存、数据库及渲染预览不纳入版本管理。若发现历史文档或研究输出中存在个人信息或凭证，应在分享仓库前进一步审查。
