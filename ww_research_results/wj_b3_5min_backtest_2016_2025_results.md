# WJ补涨策略：唯一5分钟执行路径回测（2016—2025）

## 核心判断

本报告只分析补涨（B3），趋势突破分支不在其中。现行5分钟回测只保留“**上一根已完成K线的峰值**”作为移动止盈依据。按该路径，2016—2025年组合总收益 **+2.90%**、年化 **+0.29%**、最大回撤 **-19.69%**、夏普（零无风险利率）**0.049**；同期中证全指累计收益约 **+14.80%**。策略目前仍没有显示出可靠的超额收益。

另一种“本根高点先出现”的路径只在当时用于执行敏感性比较；按你的决定，它不再是策略模式或回测输出。选择上一根峰值的原因是执行时只用当时已完成的数据，不把当前5分钟K线尚未结束的最高价倒灌进此前的止损线。

## 卖点依据

**买入后最高价回撤5%，全部卖出**是你明确否决“涨10%先卖一半、余仓再按回撤3%卖出”后确定的规则，并非我根据回测收益挑选参数。WJ正式版写明：买入后跟踪持仓最高价，回撤达到5%时卖出全部剩余仓位，不设+10%分批止盈门槛。见[正式版止损与止盈纪律](../WJ策略_v1.4_EXPMA整合正式版.md#L697)和[策略历史整理](../latest_wj_strategy_from_logs.md#L459)。

本次补涨退出执行为：

- **初始硬止损**：从买入价下跌5%，盘中触发即卖。
- **移动止盈**：每根5分钟K线只检查由上一根已完成K线的最高价确定的止损线；本根开盘或最低价触及就卖。若未触发，收盘后才将本根最高价纳入峰值，供下一根K线使用。
- **MA5/时间退出**：收盘跌破MA5，或持有满3个交易日仍未达到+2%，次日首根5分钟K线退出。
- **持仓上限**：7个股票交易日。

WJ原文还包含“日线跌破平台下沿或MA5即离场”；这次可复现模拟实现了收盘跌破MA5，未将平台下沿单独加入，因为当前代理信号没有可靠的平台价位。MA5和时间退出采用次日首根5分钟K线执行，是回测成交代理，不是逐笔实盘委托复刻。

## 补涨筛选与入场口径

信号筛选仍是量价代理，不等同于完整的历史题材复盘：

- 候选股满足120日窄幅横盘（区间不超过20%），或距120日高点回撤至少30%、近20日窄幅整理；同时要求量能较此前5日均量至少放大50%、此前20日涨幅不超过20%、信号日涨幅不超过2%、收盘价未明显远离120日前高。
- 领涨股代理来自同一“当前行业”分类：此前10日涨幅至少50%或连续涨停至少6日，随后断板；也纳入高开走弱代理。
- 领涨股健康过滤：信号日收盘距近10日高点回撤不超过15%、收盘不低于MA5；计划入场日不低于前一日MA5，且不低开5%或更多。这些是回测操作化阈值。
- 每个信号日最多保留5只补涨候选。按B.5，下一交易日分时涨幅不超过2%时买入：开盘已在+2%以内的按开盘价成交；开盘高于+2%、后续5分钟最低价触及+2%时，按+2%限价模拟成交。

历史周主线、历史题材成分和点时基本面没有进入筛选；当前行业分类回看历史会产生行业/题材代理误差。

## 结果

| 指标 | 补涨组合结果 |

| 补涨信号 | 1,178 |
| 可执行候选交易 | 1,146 |
| 组合接纳交易 | 1,134 |
| 组合总收益 | +2.90% |
| 年化收益 | +0.29% |

| 夏普（零无风险利率） | +0.049 |
| 中证全指同期累计收益 | +14.80% |

候选交易胜率 **39.79%**，平均净收益 **+0.038%**，盈亏因子 **1.027**。1,146笔候选中，1,121笔在5分钟K线开盘成交，25笔按+2%限价触及成交；10个信号没有触及入场条件，2个信号缺少可用的分钟窗口，另有同标的持仓重叠被跳过。单笔往返成本按0.30%，组合最多持有10只。

退出原因：MA5/3日时间退出753笔；买入后高点回撤5%退出349笔；买入价-5%硬止损26笔；7日上限11笔；样本结束7笔。可见这套代理的结果不只由移动止盈决定，MA5和时间退出占比更高。

## 判断边界

这些结果没有做参数寻优，5%回撤值来自你的策略决定；它不是这轮历史收益优化出来的“最优点”。+0.29%的年化和0.049的夏普都接近零，且明显落后基准。信号、行业映射、平台下沿和分时成交仍有代理误差，回测结果不应解释为已验证实盘有效。
